# Zhicong Portfolio

Personal UX and brand design portfolio built with React and Vite.

## Local Development

Requires Node.js 18 or later.

```sh
npm install
npm run dev -- --port 5175
```

Open http://127.0.0.1:5175/.

## Production Build

```sh
npm run build
npm run preview
```

The production output is generated in `dist/`. Uploading this repository
does not automatically publish the website.

## Structure

- `src/`: React components, project content, and styles.
- `public/assets/`: Portfolio images, logos, and videos.
- `index.html`: Page entry and browser tab title.

Environment files, dependencies, build output, and local editor caches
are excluded from version control. Never commit license keys or tokens.
